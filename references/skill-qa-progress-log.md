This is the live, append-only record for the evidence-first SKILL.md QA process.
Each completed skill has five independent real-model scenarios: normal, missing input,
edge, failure, and hallucination. A skill is changed only after its own recorded evidence.

Running context and handoff details: `references/qa-running-context.md`.

## Run rules

- Protocol: `tools/real_skill_poc_qa.mjs` v3.6.0; Node.js only.
- Real-model roles: designer, independent design auditor, target chat, and independent judge.
- Test prompts are committed before target execution. Retests keep their user prompts
  byte-for-byte identical.
- The runner rejects Python use, reads outside the isolated workspace, unauthorized external
  actions, changed fixtures, missing expected artifacts, and malformed artifacts.
- A timestamped pre-change archive is retained outside the repository:
  `/Users/abhi/Downloads/sme-ops-system-builder-backups/sme-ops-system-builder-20260928-013815-+0545.zip`.
