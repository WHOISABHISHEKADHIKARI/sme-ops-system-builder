Material a module may need but should not carry inline.

| File | What it is | Loaded at runtime? |
|---|---|---|
| [catalog.md](catalog.md) | all 100 modules, grouped by layer, with what each is for | No - only when someone asks what is available |

`catalog.md` is deliberately not part of any module's `SKILL.md`. A module that loaded
the whole catalog would pull 100 descriptions into every conversation to answer a
question about one table. Route from `sme-ops-system-builder` instead; the catalog is
for a human deciding what to install.

The catalog is generated from the same field reference the modules use, so a module
that exists is a module that is listed, and a module that is listed has a passing
`tools/check.py`.
